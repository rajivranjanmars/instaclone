# Instagram clone

A React photo-sharing application using Firebase authentication and storage, Chakra UI components, and client-side routing.

## Quick start

Run `npm ci` and `npm run dev`; `npm run build` creates the production bundle. Configure your Firebase project in the existing Firebase initialization module before connecting to live services.
